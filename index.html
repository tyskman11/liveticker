Einstellungen

Die Auswahl wird nur in diesem Browser gespeichert. Während eines Live-Spiels wird weiterhin spätestens alle 12 Sekunden aktualisiert.

Anleitung

  1. Starte auf der NAS sh start-websites.sh; das startet Gate und API gemeinsam.
  2. Rufe die API-Basisadresse auf und prüfe /health.
  3. Nutze die Endpunkte unten in einer App oder einem Dashboard.

Die Website funktioniert auch ohne laufenden API-Server über ihre direkten, offiziellen Datenquellen.
